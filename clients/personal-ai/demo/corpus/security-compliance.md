# 安全与合规

## 数据安全
- 本地数据默认加密存储，API Key 只放在 .env，绝不入库（.gitignore 排除）。
- 私有数据（Obsidian 笔记、记忆、复盘）只允许私有入口访问，公开入口做权限过滤。
- 工具执行前校验权限：公开人格不能调用私人工具。

## 合规要求
- 遵守 GDPR：用户有权导出与删除自己的全部数据。
- 遵循最小授权原则，按需返回数据，使用 limit 限制数量。
- 日志不记录敏感内容（API Key、完整个人数据）。

## 保密与隐私
公开知识库仅包含对外展示的公开信息；一切个人偏好、笔记、行动项均视为私密数据，禁止同步到任何外部服务。
